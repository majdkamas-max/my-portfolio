MAJD KAMAS — BUSINESS PORTFOLIO

HOW TO OPEN
1. Extract this ZIP to a folder.
2. Open portfolio/index.html in a modern browser.
3. To publish it, upload the contents of this folder to a static hosting provider.

FILES
- index.html: portfolio structure and bilingual Arabic/English content
- style.css: responsive executive design, animations, compact profile portrait, continuous technology ticker (direction-independent in Arabic and English), animated code panel, and glowing cursor
- script.js: language toggle, typing headline, scroll reveals, animated code samples, mobile menu, project lightbox, and cursor behavior
- me.webp: supplied profile portrait, optimized for web
- cv.pdf: supplied CV
- association.webp: charity-association management interface preview
- shop.webp: clothing e-commerce storefront preview
- pharmacy.webp: desktop-style pharmacy management interface preview

FEATURES
- The education block is replaced by an animated code workspace.
- Portfolio project images open in a lightbox; each card has a separate repository link.
- The email actions open a Gmail compose page addressed to majdkamas@gmail.com, avoiding dependence on a configured Windows mail application.
- React, Python, and Bootstrap are included in the moving technology strip as requested.
- The page runs as a static site; no PHP, database, npm, or build step is required. Google Fonts are optional and system fonts are used as fallback.

PROJECT-PREVIEW NOTE
The project visuals are interface mockups based on the project descriptions supplied for the portfolio. They are not live application data or screenshots captured from the repositories. Existing GitHub repository URLs remain attached to each project.

التحديث الأخير: مؤشرات عمل احترافية، عداد 20 عميلاً وفق المعلومات المقدمة، شريط تقنيات دائري مستمر، وبيان واضح بأن النجوم معيار جودة مستهدف وليست تقييمات عملاء موثقة.
